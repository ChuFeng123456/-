## 原型使用说明

- 光云原型：浏览器打开 `06_光云_原型/prototype.html`，左侧导航可在 13 个页面间切换；`png/` 内是 13 张 2880×2000 页面截图，`svg/` 内是 13 个可拖入 Figma 的矢量线框。
- 网吧交友助手原型：浏览器打开 `10_网吧交友助手_原型/prototype.html`，共 9 页，其中语音消息、吧主入驻、图片动态为二期占位页；`png/` 与 `svg/` 分别提供页面截图与可编辑线框。

## 数据口径说明

- 竞品与市场数据来自公开渠道，各文档末尾列有来源链接；微信内容安全 API、合法域名等合规要求以微信官方文档为准。
- 公司内部指标（销量、好评率、使用率、留存、转写准确率、同步耗时、差评占比、匹配成功率等）为示例/假设值，文档与周报中已标注，引用前替换为真实数据。

## 功能取舍说明

讯飞录音笔选定功能：A 一键转写+要点提炼、B 说话人分离与角色标注、E 会议纪要+待办自动生成、F 云同步+多端协作、G 长续航+边充边录。A/B/E/F 合并为软件模块 PRD，G 作为整机与硬件需求写入产品需求文档。
